# Pengaturan

![Halaman Pengaturan SWAT](/img/web/settings.png)

Halaman Pengaturan memungkinkan Anda menyesuaikan tampilan dan preferensi aplikasi.

## Tampilan

Pilih tema antarmuka:

- **Sistem** — mengikuti pengaturan tema perangkat Anda (terang atau gelap).
- **Terang** — selalu menggunakan tema terang.
- **Gelap** — selalu menggunakan tema gelap.

Pilihan Anda disimpan otomatis di peramban (browser) yang Anda gunakan.

## Bahasa

Pilih bahasa antarmuka aplikasi:

- **Bahasa Indonesia** (id-ID)
- **English** (en-US)

Setelah Anda memilih bahasa, semua label menu, tombol, dan pesan akan berubah sesuai pilihan.
Pilihan Anda disimpan otomatis.

## Pelacakan (GPS)

Jika Anda memiliki izin mengelola aturan penyimpangan rute, bagian **Pelacakan** akan muncul.
Di sini Anda dapat menyesuaikan parameter GPS:

- **Jarak koridor** — toleransi penyimpangan rute dari jalur yang direncanakan.
- **Durasi berhenti** — berapa lama kendaraan boleh berhenti tanpa dianggap menyimpang.
- **Keterlambatan** — toleransi waktu untuk penyelesaian pengangkutan.

:::note Izin khusus diperlukan
Bagian ini hanya muncul jika akun Anda memiliki izin `pelacakan:kelola` (atau setara).
Hubungi administrator jika merasa seharusnya dapat mengakses pengaturan ini.
:::

## Tentang

Bagian **Tentang** menampilkan informasi umum aplikasi:

- Nama aplikasi (SWAT)
- Instansi yang mengoperasikan
- Versi aplikasi saat ini
