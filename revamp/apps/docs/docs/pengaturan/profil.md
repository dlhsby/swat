# Profil

![Halaman Profil SWAT](/img/web/profile.png)

Halaman Profil menampilkan informasi akun Anda dan menyediakan kontrol untuk keamanan serta sesi.

## Informasi Akun

Kartu **Informasi Akun** menampilkan detail profil Anda:

- **Avatar** — foto profil (jika ada) atau inisial nama.
- **Nama Lengkap** — nama yang terdaftar di sistem.
- **Nama Pengguna** — identitas unik Anda (dimulai dengan `@`).
- **Peran** — peran akun Anda dalam sistem (misalnya: Administrasi, Pengecekan, Operator, dst).

Informasi ini ditampilkan dari data profil di basis data dan tidak dapat diubah di halaman ini.
Hubungi administrator jika perlu memperbaharui informasi profil.

## Keamanan

Kartu **Keamanan** memungkinkan Anda mengelola kata sandi:

1. Klik tombol **Ubah Kata Sandi**.
2. Anda akan diarahkan ke halaman [Ganti Kata Sandi](/pengaturan/ganti-kata-sandi).
3. Masukkan kata sandi saat ini, kata sandi baru, dan konfirmasi.

:::tip Ganti kata sandi secara berkala
Untuk menjaga keamanan akun, disarankan untuk mengganti kata sandi secara berkala
(misalnya setiap 3 bulan).
:::

## Sesi

Kartu **Sesi** menampilkan kontrol untuk perangkat saat ini:

1. Klik tombol **Keluar** untuk mengakhiri sesi dan kembali ke halaman masuk.
2. Anda harus masuk kembali dengan nama pengguna dan kata sandi untuk melanjutkan.

:::note Satu sesi per perangkat
Tombol **Keluar** hanya mengakhiri sesi pada perangkat saat ini. Jika Anda masuk dari
perangkat lain, sesi di perangkat tersebut akan tetap aktif.
:::
